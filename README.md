# Time Sorter

A puzzle game made for [GitHub Game Off 2026](https://itch.io/jam/game-off-2026). Theme: **Shift**.

You are an extra-dimensional creature whose job is sorting time. Each shift, you take over a human body in a room overlooking a real historical event. Work out the exact date from the evidence around you, mark it on the calendar, and hit the required score before your shift ends.
